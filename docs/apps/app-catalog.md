# App Catalog

The Start menu launches ten applications. Each is a function in `kernel.c`
that paints a window, processes input, and returns when closed.

## Productivity apps

### 1. Calculator — `calculator_ui()`
A 4×4 keypad (`789/ 456* 123- 0.= +C`). It maintains a character
buffer `expr[64]` and evaluates a left-to-right expression supporting
`+ - * /` (`calc_eval` — note: no operator precedence, simple
accumulator). `C` clears, `=` evaluates. The result is written back into
the expression buffer.

### 2. Browser (Posts) — `browser_ui()`
Fetches `http://jsonplaceholder.typicode.com/posts/2` and renders the raw
HTTP body (truncated to the content area, "~90 lines" at 10px). Flow:
`parse_url` → `dns_resolve` → `http_get_by_ip_port`; if that fails but
the IP resolved, falls back to `tls_http_get_by_ip`. A red **X** closes.

### 3. JSON Viewer (Users) — `json_viewer_ui()`
Fetches `http://jsonplaceholder.typicode.com/users/1`, then parses it with
the bundled **JSMN** parser (`json.h`) and prints `key: value` pairs from
the top level. Demonstrates real TLS/HTTP + JSON parsing on-screen.

### 4. Text Editor — `text_editor_ui()`
A keyboard-driven editor over `editor_text[1024]`. Keys append to the
buffer; **Backspace** deletes; buttons **Save / Load / Back / Clear / NBU**
manage an in-memory saved copy (`editor_saved_text`). Shows a live char
count and a dirty `*` flag. This is the only app that accepts free-form
typing.

## Game apps

### 5. Click Game — `click_game_ui()`
Click the blue rounded target to score; it relocates pseudo-randomly using
`(target_idx * 83) % (ww-120)` / `(* 47) % (wh-150)`. Score shown
top-right.

### 6. High-Low Cards — `high_low_card_ui()`
A playing-card guessing game. Keyboard: **H** = next higher, **L** = next
lower, **N** = reveal next card, **R** = reset, **Q** = quit. Cards are
generated by an LCG (`next_card_rank`, `seed = framebuffer W+H+97`).
Tracks `score` and `best`.

### 7. Keyboard Maze — `keyboard_maze_ui()`
An 8×13 ASCII maze (`maze_reset`). Move with **WASD**, collect `.`
coins (score), reach `G` to win, **R** resets, **Q** quits.

### 8. Snake Game — `snake_game_ui()`
Classic snake on a 16×12 grid. **WASD** step one cell (no reverse),
eat the red food to grow + score, **R** resets, **Q** quits. Collision
with walls or self ends the game (`game_over`). Food placement avoids the
snake body (`snake_place_food`).

### 9. Grocery Shop — `grocery_shop_ui()`
A shopping list of 8 items (`grocery_items[]`) with prices in ₹. Click a
row (or press `1`–`8`) to add; **Backspace** removes; **C** clears;
**Enter**/"Collect" "pays". A decorative pseudo-**QR code**
(`draw_fake_qr`, deterministic from total) is shown beside a live total.

## System app

### 10. System Info — `system_info_ui()`
Read-only panel: NBU project name, UI label, display resolution
(`framebuffer_width × height`), USB device count, network readiness, and a
list of available programs/games.

---

Every app returns to the desktop on close (see
[Desktop & Shell](desktop.md)).
